# Pesquisa de Projetos no GitHub que Consomem APIs (Aula 04 — Atividade 01)

Abaixo estão 10 projetos públicos do GitHub pesquisados e analisados, identificando o framework/biblioteca Front-end utilizado e as APIs consumidas em cada aplicação.

| # | Projeto (Repositório GitHub) | Framework / Stack | API Consumida | Funcionalidades Observadas |
| :---: | :--- | :--- | :--- | :--- |
| **1** | [`IdoBouskila/Pokedex`](https://github.com/IdoBouskila/Pokedex) | React + Vite + React Query | **PokéAPI** (`pokeapi.co`) | Listagem de Pokémon, filtro por tipo e modal de detalhes com estatísticas e evoluções. |
| **2** | [`adrisons/react-pokemon`](https://github.com/adrisons/react-pokemon) | React 19 | **PokéAPI** (`pokeapi.co`) | Arquitetura modular com listagem, visualização detalhada e comparação entre Pokémon. |
| **3** | [`rajdeepratan/weather-app`](https://github.com/rajdeepratan/weather-app) | React + TypeScript + React Query | **Weather API** e **Google Places API** | Previsão do tempo global com autocompletar de localização e interface responsiva. |
| **4** | [`abdelilah-elaziri/app-weather-react`](https://github.com/abdelilah-elaziri/app-weather-react) | React + Tailwind CSS | **OpenWeatherMap API** | Consulta em tempo real de temperatura, umidade e condições climáticas por cidade. |
| **5** | [`stamorim28/vue-minha-pokedex`](https://github.com/stamorim28/vue-minha-pokedex) | Vue 3 + Pinia + Axios | **PokéAPI** (`pokeapi.co`) | Paginação, pesquisa de Pokémon, carregamento dinâmico de imagens e modal de detalhes. |
| **6** | [`nothingnothings/VueDex`](https://github.com/nothingnothings/VueDex) | Vue 3 + Vue Router + TypeScript + Axios | **PokéAPI** (`pokeapi.co`) | SPA com roteamento entre telas, pesquisa e gerenciamento de estado local. |
| **7** | [`gustperx/vue-pokedex`](https://github.com/gustperx/vue-pokedex) | Vue + TypeScript + Vite + Tailwind CSS + Axios | **PokéAPI** (`pokeapi.co`) | Consumo assíncrono de endpoints REST com Axios e estilização utilitária. |
| **8** | [`ahmetselimboz/nextjs-movie-app`](https://github.com/ahmetselimboz/nextjs-movie-app) | Next.js + Tailwind CSS | **TMDB API** (The Movie Database) | Busca de filmes, página de detalhes e gerenciamento de favoritos. |
| **9** | [`oktay/movies`](https://github.com/oktay/movies) | Next.js (App Router) + TypeScript + Tailwind CSS | **TMDB API** (The Movie Database) | Server Components, paginação, filtros, trailers e informações do elenco. |
| **10** | [`alok722/github-profile-searcher`](https://github.com/alok722/github-profile-searcher) | Angular + Firebase | **GitHub REST API** (`api.github.com`) | Busca de perfis de usuários, contagem de repositórios, seguidores e dados públicos. |
